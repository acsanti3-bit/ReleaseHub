# IWS ReleaseHub

O **IWS ReleaseHub** é uma plataforma interna desenvolvida para centralizar o acompanhamento de releases, versões, ambientes, compatibilidades e tarefas relacionadas aos sistemas da IWS.

A solução foi criada para apoiar principalmente os processos de **Qualidade**, facilitando o acompanhamento das versões em validação e reunindo em um único local informações utilizadas durante o processo de liberação.

---

## Objetivo

O ReleaseHub tem como principal objetivo melhorar a organização e a visibilidade do processo de releases.

A plataforma busca reduzir controles manuais, facilitar o acompanhamento das versões e tornar as informações mais acessíveis para as equipes envolvidas no processo.

Entre os principais benefícios estão:

* centralização das informações das releases;
* acompanhamento do andamento dos projetos;
* visualização das tarefas por situação;
* controle das versões utilizadas nos ambientes;
* acompanhamento da compatibilidade entre sistemas;
* apoio às equipes de Qualidade, Desenvolvimento, Suporte e Implantação;
* rastreabilidade das alterações realizadas no sistema.

---

## Dashboard

O Dashboard apresenta uma visão geral das releases cadastradas e permite acompanhar rapidamente o andamento dos projetos.

São disponibilizados indicadores relacionados às releases, projetos, versões, tarefas, situações e progresso.

O painel também reúne informações importantes para o acompanhamento operacional das versões.

---

## Releases

A área de Releases permite organizar e acompanhar as versões que estão passando pelo processo de validação e liberação.

As releases podem reunir diferentes projetos e ambientes, permitindo uma visão consolidada das informações relacionadas a cada ciclo.

---

## Ambientes

Os ambientes permitem organizar as diferentes configurações utilizadas durante o acompanhamento das releases.

Cada ambiente pode possuir informações próprias relacionadas aos projetos e versões utilizadas.

---

## Compatibilidade

A área de Compatibilidade permite consultar e organizar as versões dos sistemas que devem ser utilizadas em conjunto.

Esse recurso auxilia principalmente as equipes que precisam identificar rapidamente quais versões são compatíveis dentro de determinado ambiente.

As informações de compatibilidade também podem ser utilizadas em outras áreas do ReleaseHub.

---

## Integração com o Redmine

O ReleaseHub utiliza informações provenientes do Redmine para auxiliar no acompanhamento dos projetos e tarefas relacionados às releases.

A integração permite centralizar informações importantes para o processo de Qualidade, reduzindo a necessidade de consultas manuais em diferentes locais.

---

## Monitoramento

O sistema possui recursos de monitoramento que auxiliam na visualização dos projetos e tarefas existentes no Redmine.

Essa área facilita a identificação de projetos que possuem atividades em andamento e auxilia na conferência das informações cadastradas no ReleaseHub.

---

## Modo TV

O **Modo TV** foi desenvolvido para permitir o acompanhamento visual das releases em monitores e televisores.

A tela apresenta informações resumidas dos projetos selecionados, permitindo que o andamento das versões seja acompanhado de forma contínua pelas equipes.

As informações são atualizadas automaticamente durante a exibição.

---

## Histórico de alterações

O ReleaseHub mantém um histórico das principais operações realizadas no sistema.

Esse recurso permite consultar alterações e identificar os usuários responsáveis pelas ações realizadas, contribuindo para a rastreabilidade e controle das informações.

---

## Controle de acesso

O acesso às funcionalidades do ReleaseHub varia de acordo com o perfil do usuário.

Os principais perfis disponíveis são:

* **Administrador**
* **Qualidade**
* **Visualizador**

As permissões são aplicadas conforme a responsabilidade de cada perfil dentro do processo.

---

## Tecnologias

O ReleaseHub foi desenvolvido utilizando tecnologias modernas voltadas para aplicações web.

Entre as principais tecnologias utilizadas estão:

* React;
* TypeScript;
* Vite;
* Node.js;
* integração com APIs;
* serviços em nuvem.
